# Hall Manager 🏨

A free, minimal web app to manage a college hall — built for **PTEC Boys Hall, Pabna Textile Engineering College**.

## ✨ Features
- 📝 New student admission with admission + monthly fee
- 💰 Monthly payments — single month or many months at once, one combined receipt
- 🧾 Printable money receipts — two copies (Office Copy + Student Copy) on half an A4 page
- 🔴 Due tracking with **Due (P+C)** — previous + current month, plus a Reminders tab
- 🔐 Real email + password login with cloud sync (Supabase) — data on any device
- 📱 Installable app (PWA) with a premium dark UI
- 📤 Backup export / import (JSON)
- 📩 One-tap SMS / WhatsApp receipt sharing
